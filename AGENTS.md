# HLD Video Plan Workspace

Use this workspace as a long-term, Git-versioned operating system for technical HLD, LLD, and system-design educational videos.

## Working rules

- Read `MASTER_VIDEO_INSTRUCTIONS.md` before beginning work on any video.
- Keep each video's materials in `videos/<video-slug>/`.
- If the user identifies an instruction that should apply to future videos, add it to `MASTER_VIDEO_INSTRUCTIONS.md`, tell the user what changed, then commit and push it when asked.
- Ideas are flexible; the video production workflow is standardized. Do not alter the standard production stages for a single video.
- Record reusable research in `research/topic-research/` and video-specific research in `videos/<video-slug>/RESEARCH.md`, with source links and dates checked.
- Separate verified facts, assumptions, and recommendations.
- Before drafting a script, create or update `BLUEPRINT.md` with the audience, goal, key message, teaching order, visual strategy, and required evidence.
- Do not publish, upload, or contact anyone unless explicitly asked.
- Preserve the user's voice and request clarification only when it would materially change the video.

## Deliverables for a video

1. `README.md` — the single entry point, status, and decisions.
2. `CHECKLIST.md` — the standardized execution checklist.
3. `RESEARCH.md` and `BLUEPRINT.md` — research and teaching design before scripting.
4. `SCRIPT.md`, `STORYBOARD.md`, and `VISUALS.md` — narration and production design.
5. `PUBLISHING.md` and `ANALYTICS.md` — packaging, performance, and learnings.
