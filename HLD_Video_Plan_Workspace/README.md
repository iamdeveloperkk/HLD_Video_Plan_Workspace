# HLD Video Plan Workspace

This is the permanent workspace for video planning and deep research. Start Codex from this folder so it automatically follows the reusable workflow in `AGENTS.md`.

```sh
cd ~/Documents/WorkSpaces/ChessMateManual/HLD_Video_Plan_Workspace
codex
```

## Structure

- `MASTER_VIDEO_INSTRUCTIONS.md` — standing instructions for every video.
- `videos/` — one folder per video, including its plan, research, script, and production notes.
- `research/` — reusable topic research shared across videos.

## Create a video workspace

Copy the template folder and replace `video-slug` with a short descriptive name:

```sh
cp -R videos/_template videos/video-slug
```
