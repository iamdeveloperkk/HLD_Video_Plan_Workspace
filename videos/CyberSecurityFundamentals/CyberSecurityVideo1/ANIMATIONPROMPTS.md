# 3. Traffic Language

### Healthy Traffic

- Blue/white
- Organized
- Consistent
- Moderate density

### Abnormal Traffic

- Red
- Increasing density
- Faster movement
- Irregular patterns

### Blocked Traffic

Red traffic reaches a security boundary and is stopped.

### Successful Attack

Red traffic crosses a security boundary and reaches a vulnerable component.
