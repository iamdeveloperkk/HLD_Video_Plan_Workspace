# Production Checklist

## Phase 1 — Idea

- [ ] Topic selected
- [ ] Target audience defined
- [ ] Objective defined
- [ ] Video type and target length defined
- [ ] Success criteria defined

## Phase 2 — Research

- [ ] Fundamentals researched
- [ ] Technical concepts researched
- [ ] Real-world implementations researched
- [ ] Architecture researched
- [ ] Trade-offs researched
- [ ] Examples researched
- [ ] Interview relevance researched
- [ ] Sources verified and dated

## Phase 3 — Video Blueprint

- [ ] Hook defined
- [ ] Problem framed
- [ ] Learning objectives defined
- [ ] Story structure defined
- [ ] Teaching order defined
- [ ] Visual strategy defined
- [ ] Interview angle defined
- [ ] Ending and CTA defined

## Phase 4 — Script

- [ ] Draft written
- [ ] Technical review completed
- [ ] Final script locked

## Phase 5 — Storyboard and visuals

- [ ] Major scenes mapped
- [ ] HLD diagrams planned or created
- [ ] LLD diagrams planned or created
- [ ] Images, screenshots, icons, and animations tracked
- [ ] Required assets ready

## Phase 6 — Voice, editing, and thumbnail

- [ ] Voice/audio recorded or prepared
- [ ] Audio reviewed
- [ ] Video edited
- [ ] Final export reviewed
- [ ] Thumbnail created and selected

## Phase 7 — Publishing and repurposing

- [ ] Final title selected
- [ ] Description and chapters finalized
- [ ] Playlist, end screen, cards, and pinned comment configured
- [ ] Video published or scheduled
- [ ] Repurposing opportunities identified

## Phase 8 — Analytics and learnings

- [ ] 24-hour metrics recorded
- [ ] 7-day metrics recorded
- [ ] 28-day metrics recorded
- [ ] What worked documented
- [ ] What did not work documented
- [ ] Changes for the next video documented
