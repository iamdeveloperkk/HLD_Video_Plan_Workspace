# YouTube Creator OS

This folder contains production standards that apply across the workspace.
Individual videos remain in `Animation_videos/` and contain their own story,
assets, and implementation details.

## Visual Production Standard

All animated technical videos should follow
[`Visual_Production_Methodology.md`](Visual_Production_Methodology.md).

Before creating or modifying animation code, review this document.

Core principle:

> Do not animate the image. Break the image into independent visual
> components and animate the components.
